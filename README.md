# NuTrace Welcome Flow

Great! Now let's build the Entry View & 2-Step Onboarding Flow based on the attached wireframes:
1. Opening / Landing Page:
   - Minimal welcome screen displaying the NuTrace logo and a primary CTA button: "Get Started".
   - Clicking "Get Started" opens or transitions into the Onboarding Wizard.
2. Onboarding Wizard (2 Steps):
   - Header with step indicator (e.g., "Step 1 of 2").
   - Step 1 (Profile): User Name input + Avatar selection. "Next" button.
   - Step 2 (Baselines): Water Goal quick-select pills (e.g., 2000ml, 2500ml) + Sleep Goal selection (e.g., 7h, 8h). 
   - CTA: "Complete Setup" button that saves preferences to local state and navigates directly to the Main Dashboard.
Please generate these initial views using React and Tailwind CSS, matching the attached wireframes. if  you have any other ideas that could benefit this onboarding process, let me know!
